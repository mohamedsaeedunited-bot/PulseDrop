# PulseDrop v3 — تطبيقك الخاص لنقل الملفات

## خطوات استخراج ملف الـ APK باللوجو الاحترافي مجاناً عبر GitHub Actions
1. فك ضغط الملف `PulseDrop-v3-Android-App.zip`.
2. أنشئ مستودعاً خاصاً (**Private Repository**) على حسابك في GitHub باسم `PulseDrop`.
3. ارفع جميع الملفات والمجلدات (تأكد من رفع مجلد `.github` ومجلد `assets`).
4. افتح تبويب **Actions** وانتظر ~4 دقائق حتى تكتمل عملية `Build PulseDrop v3 Android APK`.
5. حمّل ملف **`PulseDrop-v3-APK`** من قسم **Artifacts** بالأسفل وثبّت `app-release.apk` على موبايلك.
